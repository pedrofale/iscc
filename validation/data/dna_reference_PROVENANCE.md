# Real DNA reference data — provenance (M4 DNA, DESIGN_inference §C.1)

Generated by `validation/data/build_dna_reference.py`. Each dataset is a public, citable DNA-seq gold standard, REDUCED to the small (coverage, alt, called-CN, het) inputs `estimate_dna` consumes and cached as a compact `.npz`. Raw sources (100s of MB–GB) are never committed or required; `validate_dna.py` loads the cache and falls back to the synthetic round-trip when absent.

## Datasets (one per DNA regime)

1. **BULK WGS — GIAB HG002** (NIST GiaB, NA24385 son). Small-variant benchmark VCF (v4.2.1, GRCh38); per-site `AD`+`GT` -> coverage/alt, CN=2, het=GT(0/1).
   `https://ftp-trace.ncbi.nlm.nih.gov/ReferenceSamples/giab/release/AshkenazimTrio/HG002_NA24385_son/NISTv4.2.1/GRCh38/HG002_GRCh38_1_22_v4.2.1_benchmark.vcf.gz`
   Fits mu_depth, kappa/nb_dispersion, het BAF; error_rate/GC prior-only (no hom-ref / reference FASTA in the reduction). Cite: Zook et al. 2019, Nat Biotechnol.

2. **SC PANEL — Mission Bio Tapestri** (KaryoTap exp01 panelv1). `dna_variants` DP/AF/NGT + `dna_read_counts` per-amplicon reads -> coverage/alt/het + amplicon-normalized CN.
   `https://zenodo.org/records/11094529/files/tapestri-experiment01-panelv1.h5?download=1` (~406 MB; not auto-downloaded).
   Fits the full single-cell layer incl. **ado_rate + beta_binom_conc** + capture_sigma. Cite: Mays et al. 2024, Zenodo 10.5281/zenodo.11094529.

3. **SC WGS — DLP+ OV2295** (Shah lab). Per-cell 500 kb-bin `reads` + HMMcopy `state` -> coverage/cn (no per-bin alleles).
   `https://zenodo.org/records/3445364/files/ov2295_cell_cn.csv.gz?download=1` (~172 MB; streamed, early-stopped).
   Fits mu_depth (low, bin units), kappa/nb_dispersion across the many CN states; ado/beta_binom/error prior-only. Cite: Laks et al. 2019, Cell 179:1207.

## Outputs (validation/data/)

- `dna_ref_hg002_bulk_wgs.npz` — bulk-wgs (built)
- `dna_ref_tapestri_sc_panel.npz` — sc-panel (built)
- `dna_ref_dlp_sc_wgs.npz` — sc-wgs (built)

## Use
`validate_dna.py` loads these via `build_dna_reference.load_reference()`; `estimate_dna` is fit on the reduction, the technical layer re-simulated, and the same summaries overlaid real vs re-sim.
