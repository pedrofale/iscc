# Real PEtracer reference data — provenance (PEtracer validation Tier 2, DESIGN_features §H/§I)

Generated by `validation/data/build_petracer_reference.py`. The dataset is the public, citable
lineage+spatial benchmark PEtracer (Weissman lab), REDUCED to the small per-tumour summary the
comparison consumes and cached as a compact `.npz`. Raw sources (100s of MB of per-tumour MERFISH +
lineage trees) are never committed or required; `validate_petracer.py --real` loads the cache and
falls back to the Tier-1 self-contained benchmark when absent.

## Dataset

**PEtracer** — Zhang, Yang, … Weissman (2025), *Science* [10.1126/science.adx3800](https://www.science.org/doi/10.1126/science.adx3800).
Mouse syngeneic tumours read jointly for **lineage** (prime-editing barcodes → a per-tumour cell
tree) and **spatial expression** (MERFISH gene panel + coordinates).

- Processed MERFISH `AnnData` (h5ad) + per-tumour lineage trees: Figshare
  [10.6084/m9.figshare.28473866](https://doi.org/10.6084/m9.figshare.28473866).
- scRNA: GEO [GSE290975](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE290975).
- Code / format reference: <https://github.com/jweissmanlab/PEtracer-2025> (`tumor_tracing/`).

**Figshare blocks automated downloads**, so `build_petracer_reference.py` does NOT auto-fetch: the
user downloads the per-tumour h5ad + lineage tree (Newick) manually and passes `--h5ad`/`--newick`.
The reducer (`reduce_petracer`, network-free) is unit-tested on tiny fixtures
(`tests/test_petracer.py::TestTier2Reducer`).

## Reduction (per tumour — never pooled across sites)

The model is a **multi-site metastasis**; multi-site inference = RESEARCH_QUESTIONS R9 (out of scope),
so every statistic is computed PER TUMOUR. The reducer computes the SAME summary as the iscc side so
the two are directly comparable:

- per-gene **lineage** (patristic tree-distance) and **spatial** (coordinate) autocorrelation
  (Moran's I — the shared `iscc.integrations.petracer._moran_all`);
- **clone-size** distribution (leaves per clade at a tree cut, or an `obs` clone column);
- **clone-territory** compactness (mean within-clone spatial spread ÷ whole-tumour spread);
- **tree** leaf count + per-cell depth distribution (balance).

Newick parsing is self-contained (no `ete3`/`cassiopeia`): `parse_newick` → patristic leaf distances.

## Outputs (validation/data/)

- `petracer_ref_<name>.npz` — one per tumour (NOT committed; built on demand from local downloads).

## Use

`validate_petracer.py --real <name> [...]` loads these via `build_petracer_reference.load_reference()`,
computes the identical summary on an iscc tumour, and overlays the distributions
(`manuscript/figures/validation_petracer_real.png`). Caveats stated in-figure/README: MERFISH ↔ F9
platform match is fine; validate per-tumour (no multi-site pooling).

## Build

```
python validation/data/build_petracer_reference.py \
    --h5ad TUMOR.h5ad --newick TUMOR.nwk --name tumor1 [--clone-key <obs_col>] [--max-cells 800]
```
